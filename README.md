## Примеры текстового форматирования

В данном разделе продемонстрированы базовые возможности визуального оформления текста:
* **Полужирный текст** используется для выделения ключевых понятий.
* *Курсивный текст* применяется для логического акцента или примечаний.
* ~~Зачёркнутый текст~~ показывает неактуальные или устаревшие данные.
* Моноширинный шрифт используется для оформления встроенных команд, например: `git status`.

### Цитата дня
> Разработчикам необходимо уметь грамотно документировать свой код. Markdown экономит время, повышает читаемость файлов README и отлично отслеживается системами контроля версий (Git).

## Математические формулы LaTeX

Markdown в репозиториях GitHub активно поддерживает интеграцию математического синтаксиса LaTeX[^latex_note].

### Встроенная (Inline) формула
Основное уравнение теории относительности Альберта Эйнштейна: \(E = mc^2\).

### Блочная (Block) формула
Пример вычисления суммы арифметической прогрессии от 1 до \(n\):
\[\sum_{i=1}^n i = \frac{n(n+1)}{2}\]
